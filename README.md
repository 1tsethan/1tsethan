## Featured project

### [Sparkling Mutuals](https://github.com/johnceoskyblock/sparkling-mutuals)

A Fabric client-side mod that helps players coordinate and track Hypixel SkyBlock Safari.

- Find sparkling critters shared by your party
- Check missing timesave critters and Safari ticket counts
- Track contests with a movable, resizable HUD

**My role:** Maintainer. Originally created by [johnceoskyblock](https://github.com/johnceoskyblock).

**Project stack:** Kotlin, Fabric, Gradle, and the Hypixel API.

[Explore the project](https://github.com/johnceoskyblock/sparkling-mutuals) · [Installation guide](https://github.com/johnceoskyblock/sparkling-mutuals#installation) · [My fork](https://github.com/1tsethan/sparkling-mutuals)

An example of my contributions: [fixing Miria contest tracking counting Agatha progress](https://github.com/johnceoskyblock/sparkling-mutuals/pull/3).
